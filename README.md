# Dr. Suman Gare — Academic Website

Responsive single-page academic portfolio prepared for GitHub Pages.

## Publish
1. Create a GitHub repository named `sumanchemphd.github.io`.
2. Upload the contents of this folder to the repository root.
3. Commit/push to `main`.
4. Open GitHub Settings → Pages → Deploy from a branch → `main` / root.
5. The site will be available at `https://sumanchemphd.github.io/`.

The supplied CV and profile photograph are already included under `assets/`.
